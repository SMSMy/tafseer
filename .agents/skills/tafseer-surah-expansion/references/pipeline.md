# المسار التفصيلي — أوامر وصيغ

المسارات في هذا المرجع نسبية إلى جذر المستودع `C:/Code-backup/tafseer-al-anam`.
الأدوات في `tools/` كُتبت للمائدة؛ عند سورة جديدة طبّق قائمة التكييف في الأسفل.

## 0) قائمة تكييف الأدوات لسورة جديدة

| الملف | ما يُعدَّل |
|---|---|
| `tools/config.json` | رابط قائمة التشغيل، رقم السورة واسمها، معرّفات المجالس ونطاقات آياتها |
| `tools/fetch_playlist.py` | ثابت PLAYLIST، وأنماط استخراج النطاق من العناوين إن اختلفت |
| `tools/make_txt.py` + `build_data.py` | نمط قبول المعرّف `re.fullmatch(r"0(6[0-9]\|70)", lid)` → مدى ids السورة الجديدة |
| `tools/maidah_lib.py` | `SURA_NAME` و`SURA_NUM`، وقاعدة المرساة إن تغيّر أسلوب بداية المحاضرين |
| `tools/verify_verses.py` | مدى ids الحلقة for، واسم المرجع |
| `tools/build_data.py` | تعبير المرساة (أول جملة الدرس حسب المحاضر) |

تسمية ملفات الأناعم/المائدة الناتجة: id من العنوان نفسه (`060 …` `071 …`).
إن جاءت سورة بأرقام تتعارض مع ids قائمة، أبلغ المستخدم فورًا — لا تعِد الترقيم من عندك.

## 3) التفريغ (ElevenLabs Scribe)

```bash
KEY=$(cat _media/el_key.txt)   # المفتاح في ملف متجاهَل فقط
curl -sS --max-time 1500 -X POST "https://api.elevenlabs.io/v1/speech-to-text" \
  -H "xi-api-key: $KEY" \
  -F "model_id=scribe_v2" -F "language_code=ara" -F "timestamps_granularity=word" \
  -F "diarize=false" -F "tag_audio_events=false" \
  -F "file=@_media/src/061.m4a;type=audio/mp4" > _media/tmp_061.json
# تحقق ثم انقل:
python -c "import json;d=json.load(open('_media/tmp_061.json',encoding='utf-8'));assert sum(1 for w in d['words'] if w.get('type')=='word')>500" \
  && mv _media/tmp_061.json raw/061.json
```

- شكل الاستجابة: `{text, words:[{text,start,end,type:word|spacing,logprob}],
  language_code:"ara", audio_duration_secs, transcription_id}` — المدة الرسمية
  من `audio_duration_secs`.
- احفظ النتائج في `raw/NNN.json` (متجاهَل عن النشر). حد الملف ≈ ساعة؛ المجلدات
  الأطول تُقسم أولًا.
- عند دفعات كثيرة: ثلاثة مسارات متوازية كل منها تسلسلي، مع إعادة محاولة ×3 وفاصل 30ث.

## 4) النص المهذب

```bash
PYTHONIOENCODING=utf-8 python tools/make_txt.py 061 > texts/061.txt
```

ثم ضرورات يدوية قبل أي بناء:
1. **حذف الانترو** من أول المقدمة حتى أول جملة الدرس (قاعدة البداية في SKILL.md).
2. **مراجعة لغوية للنص كاملًا** قراءةً وتركيزًا: أخطاء التفريغ الشائعة تكرار كلمة،
   انقسام جملة في منتصفها، كلمات إنجليزية دخيلة (مثل `Straight` أو `غrma`)،
   تشويه أسماء («الأترجة» ترد «العترجة/الإترجة»)، علامات `--`، وأقواس ناقصة.
   لا تُعِد الصياغة — صحّح فقط؛ النص موقوت بالكلمة والمحاذاة حساسة للانحراف.
3. تحقق: أول سطر بعد «■ المقدمة…» هو جملة بداية الدرس الصحيحة للمحاضر.

صيغة TXT (مطابقة لمرجع `خلود/نصوص/` للأنعام):
```
================================================================================
❖ دورة الأترجة القرآنية • المجالس التفسيرية ❖
تفسير سورة <الاسم>
المجلس <الترتيب بالكلمة> : من الآية 1 إلى الآية 18
فضيلة الشيخ الدكتور / د. <المحاضر>
================================================================================

════════════════════════════════════════════════════════════════════════════════
■ المقدمة والمدخل إلى موضوع المجلس:
════════════════════════════════════════════════════════════════════════════════

<فقرة>

--------------------------------------------------------------------------------
◈ تفسير الآية الكريمة رقم (2):
﴿ <النص العثماني كاملًا> ﴾ [<السورة>: <رقم مشرقي>]
--------------------------------------------------------------------------------

<فقرة>…
```

## 5) بناء البيانات والفهرس والتحقق

```bash
for id in 060 061 062 063 064 065 066 067 068 069 070; do
  PYTHONIOENCODING=utf-8 python tools/build_data.py $id < texts/$id.txt > data/$id.json
done

```

- بنية `data/NNN.json` وحقولها موثقة في README بالمستودع (`source_editions`
  تذكر صراحة إن كان النص مهذبًا آليًا أو منقّحًا بشريًا).
- `index.json`: `suras[]` كل عنصر `{slug,number,name,page,lectures[]}` — والصفحة
  صفحة الفهرس (`maidah.html`…). ids فريدة عالميًا فتبحث `findLecture` عبر السور.
- نسبة المحاذاة تُطبع على stderr. 100% المتوقعة للمهذب الآلي تنخفض قليلًا بعد
  المراجعة البشرية — أقل من 95% يعني مشكلة حقيقية (انظر lessons قبل لمس النص).

- صفحة فهرس السورة: انسخ هيكل `maidah.html` وغيّر العنوان والإحصائيات و
  `data-sura="<slug>"` على body وروابط البدء.
- بطاقة السورة في `index.html` (اختيار السورة): الإحصائيات تُحسب من config
  (عدد المجالس، مجموع المدد/3600، عدد الآيات من الطبعة).
- `watch.html/js` عامة أصلًا — لا تُعدَّل لسورة جديدة.
- ارفع `?v=` في أي HTML عدّلت أصوله.
