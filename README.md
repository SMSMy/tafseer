# tafseer-al-anam — تفسير سورة الأنعام (نصوص متزامنة)

نصوص محاضرات «دورة الأترجة القرآنية» لتفسير سورة الأنعام، مهيّأة للمزامنة مع التشغيل
(تظليل الجملة الجارية + تمرير تلقائي، مع إمكانية رجوع المستخدم للأعلى لقراءة ما سبق).

> **حالة المشروع: قيد الإعداد — لا يُرفع إلى GitHub قبل مراجعة وموافقة المالك.**

## مصادر النص

النص المعتمد هو **النسخة المنقحة من المالك** (ملفات DOCX/TXT في «خلود\نصوص»):
إملاء مصحّح + تشكيل + الآيات بالرسم العثماني داخل ﴿ ﴾ مع مرجعها [الأنعام: N].
الأزمنة مأخوذة من Scribe v2 (language_code=ar) وتمّت محاذاتها على مستوى الكلمة.

**ملاحظة جوهرية:** الآيات القرآنية والعناوين التحريرية (مثل «◈ تفسير الآية الكريمة رقم N»
و«المقدمة والمدخل إلى موضوع المجلس») **ليست منطوقة في التسجيل** — المحاضر يشرح ويستشهد
بأجزاء من الآيات داخل كلامه فقط. لذلك تُعرض ككتل قراءة ثابتة ولا تدخل المسار الزمني.

## البنية

```
index.json        فهرس المحاضرات الاثنتي عشرة (يُقرأ أولًا)
data/NNN.json      بيانات كل محاضرة (مقاطع منطوقة موقوتة + آيات/عناوين ثابتة)
data-scribe/      نسخة سابقة (مبنيّة على Scribe فقط) — مرجع للمقارنة، لا تُنشر
raw/              استجابة Scribe الخام — لا تُنشر
```

## شكل `data/NNN.json`

```json
{
  "id": "071",
  "title": "تفسير سورة الأنعام من الآية 1 إلى الآية 18",
  "speaker": "د. محمد بن عبد العزيز الخضيري",
  "series": "تفسير سورة الأنعام",
  "channel": "دورة الأترجة القرآنية",
  "language": "ar",
  "duration": 2409.581,
  "youtube_id": "albg1ik7lSQ",
  "youtube_url": "https://www.youtube.com/watch?v=albg1ik7lSQ",
  "embed_url": "https://www.youtube.com/embed/albg1ik7lSQ",
  "source_editions": ["scribe_v2 (timestamps)", "docx_reviewed (text)"],
  "segments": [
    { "id": 0, "type": "heading", "timed": false, "text": "المقدمة والمدخل إلى موضوع المجلس" },
    { "id": 1, "type": "text",    "timed": true,  "start": 6.66, "end": 15.34,
      "text": "الحمد لله رب العالمين …",
      "words": [ { "text": "الحمد", "start": 6.66, "end": 7.02 }, … ] },
    { "id": 2, "type": "quran",   "timed": false, "ref": "الأنعام 2",
      "text": "﴿ هُوَ ٱلَّذِى خَلَقَكُم … ﴾" }
  ]
}
```

- `type`: `text` = كلام منطوق (موقوت) · `quran` = آية قرآنية (ثابتة) · `heading` = عنوان تحريري (ثابت).
- `timed=true` للمقاطع المنطوقة فقط؛ لها `start/end` و`words` بأزمنة بالثواني.
- `timed=false` للآيات والعناوين: بدون `words`، تُعرض كصناديق قراءة/فواصل ولا تؤثر في المزامنة.
- المحاذاة: مقارنة تطابق على مستوى الكلمة بعد تطبيع الرسم (إزالة التشكيل وتوحيد الهمزة/الياء/التاء المربوطة)، والكلمات غير المطابقة تأخذ أزمنة مستوفاة خطيًا بين أقرب مطابقتين.
- الأرقام داخل الآيات والمراجع عربية مشرقية كما في النسخة المصدر.

## التشغيل والمزامنة (عند بناء الموقع)

- **وضع الفيديو**: YouTube IFrame Player API + قراءة `player.getCurrentTime()` للمزامنة.
- **وضع الصوت**: ملف صوت مضغوط (64kbps mono) عبر `<audio>` — يُضاف عند الطلب.
- التمرير التلقائي: تمرير ناعم للمقطع النشط (`scrollIntoView({behavior:'smooth', block:'center'})`)،
  ويتوقف عند تفاعل المستخدم (wheel/touch/keyboard) ويُستأنف بعد خمول، والرجوع للأعلى دائمًا متاح.
- الآيات والعناوين كتل ثابتة في التدفق؛ يمكن تمييزها بإطار أخضر/ذهبي وزر "استمع للآية" لاحقًا.

## المصدر والحقوق

المقاطع منشورة على قناة **دورة الأترجة القرآنية** على يوتيوب (الروابط في `index.json` وكل ملف).
النص القرآني مأخوذ من نسخة المالك المنقحة؛ ينبغي التدقيق قبل النشر العام.
