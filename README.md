# tafseer — تفسير سورة الأنعام (نصوص متزامنة)

المجالس التفسيرية الاثنا عشر كاملة لسورة الأنعام من «دورة الأترجة القرآنية»، تعمل كموقع ثابت
على GitHub Pages: **https://smsmy.github.io/tafseer/**

## للزائر والطالب — طريقة الاستخدام

- استمع بالفيديو (يوتيوب) أو بصوت فقط (ملفات mp3 مضغوطة 48kbps داخل المستودع).
- النص يسير معك: تُظلَّل الجملة الجارية، والشاشة تنزلق تلقائيًا إلى موضعها.
- يمكنك النقر على أي جملة أو كلمة للانتقال إلى موضعها في التسجيل.
- التمرير التلقائي يتوقف مؤقتًا حين تتدخل يدويًا، ويُستأنف تلقائيًا بعد لحظات،
  أو تعود إليه بالزر العائم «متابعة الاستماع».
- الآيات مطوية افتراضيًا ويمكن توسيعها فرديًا أو توسيع الكل دفعة واحدة.
- يُحفظ موضعك في كل مجلس على جهازك — وتُسأل عند العودة إن أردت المتابعة من حيث توقفت.
- يعمل الموقع بدون خادم خلفي (ملفات ثابتة)، ويصلح للقراءة والطباعة (نمط طباعة مُهيأ).

## كيف أُعدّ هذا النص

1. **النص المعتمد** هو النسخة المنقحة من المالك (ملفات DOCX/TXT): إملاء مصحّح + تشكيل +
   الآيات بالرسم العثماني داخل ﴿ ﴾ مع مرجعها [الأنعام: N].
2. **الأزمنة** من ElevenLabs Scribe v2 (language_code=ar)، ومحاذاتها تتم على مستوى الكلمة
   بعد تطبيع الرسم (إزالة التشكيل وتوحيد الهمزة/الياء/التاء المربوطة)؛ والكلمات غير
   المطابقة تأخذ أزمنة مستوفاة خطيًا بين أقرب مطابقتين.
3. **التحقق من الآيات**: قورنت الكتل الـ159 بإصدار `quran-uthmani` — النتيجة مطابقة 159/159
   (التفاصيل في `VERIFICATION.md`).
4. الآيات القرآنية والعناوين التحريرية (مثل «تفسير الآية الكريمة رقم N»)
   **ليست منطوقة في التسجيل** — المحاضر يشرح ويستشهد بأجزاء من الآيات داخل كلامه فقط؛
   لذلك تُعرض ككتل قراءة ثابتة خارج المسار الزمني.

## البنية

```
index.html         الصفحة الرئيسية — فهرس المجالس
watch.html         صفحة المجلس — مشغل + نص متزامن (?id=071 … 082)
index.json         فهرس المحاضرات الاثنتي عشرة
data/NNN.json      بيانات كل محاضرة (مقاطع منطوقة موقوتة + آيات/عناوين ثابتة)
audio/NNN.mp3      صوت مضغوط 48kbps mono للتشغيل دون يوتيوب
assets/            css/js والأيقونة
VERIFICATION.md    تقرير مطابقة الآيات للطبعة العثمانية
```

> `raw/` (استجابة Scribe الخام) و`data-scribe/` (البنية الأولى) موجودان محليًا فقط ولا يُرفعان.

## شكل `data/NNN.json`

```json
{
  "id": "071",
  "title": "تفسير سورة الأنعام من الآية 1 إلى الآية 18",
  "speaker": "د. محمد بن عبد العزيز الخضيري",
  "series": "تفسير سورة الأنعام",
  "channel": "دورة الأترجة القرآنية",
  "language": "ar",
  "duration": 2409.581,
  "youtube_id": "albg1ik7lSQ",
  "youtube_url": "https://www.youtube.com/watch?v=albg1ik7lSQ",
  "embed_url": "https://www.youtube.com/embed/albg1ik7lSQ",
  "source_editions": ["scribe_v2 (timestamps)", "docx_reviewed (text)"],
  "segments": [
    { "id": 0, "type": "heading", "timed": false, "text": "المقدمة والمدخل إلى موضوع المجلس" },
    { "id": 1, "type": "text",    "timed": true,  "start": 6.66, "end": 15.34,
      "text": "الحمد لله رب العالمين …",
      "words": [ { "text": "الحمد", "start": 6.66, "end": 7.02 }, … ] },
    { "id": 2, "type": "quran",   "timed": false, "ref": "الأنعام 2",
      "text": "﴿ هُوَ ٱلَّذِى خَلَقَكُم … ﴾" }
  ]
}
```

- `type`: `text` = كلام منطوق (موقوت) · `quran` = آية قرآنية (ثابتة) · `heading` = عنوان تحريري (ثابت).
- `timed=true` للمقاطع المنطوقة فقط؛ لها `start/end` و`words` بأزمنة بالثواني.
- `timed=false` للآيات والعناوين: تُعرض كصناديق قراءة/فواصل ولا تؤثر في المزامنة.
- الأرقام داخل الآيات والمراجع عربية مشرقية كما في النسخة المصدر.

## المصدر والحقوق

المقاطع منشورة على قناة **دورة الأترجة القرآنية** على يوتيوب (الروابط في `index.json` وكل ملف).
اعدّ الموقع من تسجيلات القناة نفسها والمدد مطابقة لها؛ النص والتقديم خدمة للطلاب.
الآيات معروضة للاستئناس ويُرجى مقابلة المصحف المطبوع في المسائل الدقيقة.
