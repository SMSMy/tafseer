# tafseer — المجالس التفسيرية (سورتا المائدة والأنعام)

موقع ثابت على GitHub Pages يجمع المجالس التفسيرية من «دورة الأترجة القرآنية» بنصٍّ
متزامن مع الصوت كلمةً كلمة: **https://smsmy.github.io/tafseer/**

- **سورة المائدة** — ١١ مجلسًا (الآيات ١–١٢٠) · د. عبد الرحمن بن معاضة الشهري (١–٦) ود. محمد بن عبد العزيز الخضيري (٧–١١).
- **سورة الأنعام** — ١٢ مجلسًا (الآيات ١–١٦٥) · د. محمد بن عبد العزيز الخضيري (١–٤) ود. عبد الرحمن بن معاضة الشهري (٥–١٢).

## للزائر والطالب — طريقة الاستخدام

- الصفحة الرئيسية لاختيار السورة أولًا، ثم تُعرض مجالسها.
- استمع بالفيديو (يوتيوب) أو بصوت فقط (ملفات mp3 مضغوطة داخل المستودع).
- النص يسير معك: تُظلَّل الجملة الجارية ثم الكلمات، والشاشة تنزلق تلقائيًا إلى موضعها.
- **انقر أي جملة أو كلمة لتنتقل إليها — وإن كان المشغل متوقفًا يُكمل التشغيل من موضعها تلقائيًا.**
- «انتقل إلى آية» ينقلك للنص ولحظة شرحها في التسجيل معًا، والآيات مطوية قابلة للتوسيع بالرسم العثماني.
- يبدأ التشغيل من أول جملة الدرس (شارة القناة الافتتاحية والختامية مستبعدة من المزامنة)،
  وزر «↺ المقدمة» يعيد إلى الصفر.
- 📄 **تحميل PDF** في شريط المشغل: النسخة الأكاديمية المنقّحة للمجلس (بالتشكيل والضبط) باسمه الكامل.
- التمرير التلقائي يتوقف حين تتدخل يدويًا ويُستأنف، موضعك محفوظ على جهازك، والتصميم متجاوب من ٣٦٠px وهو مناسب للهواتف.

## نسختان بمقصدين مختلفين — لا تُخلط

| | الموقع | ملف PDF |
|---|---|---|
| الغرض | **تفريغ أمين للمنطوق** مع إمكانية التتبع كلمةً كلمة | **نسخة أكاديمية منقّحة** للتدريس والطباعة |
| النص | مهذب من التفريغ الآلي ثم مراجعة لغوية، وفوقه المراجعة البشرية عند توفّرها | النص المنقّح البشري بالتشكيل وضبط الآيات |
| المزامنة | كلمة بكلمة مع التسجيل | لا ينطبق |
| المصدر | `texts/NNN.txt` ← `data/NNN.json` | `خلود/نصوص/<السورة>/ملفات_PDF` ← `pdf/NNN.pdf` |

لذلك قد يختلف النصان في تشكيل أو صياغة أو حذف ثرثرة المنطوق — وهذا مقصود.

## بنية المستودع

```
index.html         الرئيسية — اختيار السورة
maidah.html        فهرس مجالس المائدة
anam.html          فهرس مجالس الأنعام
watch.html?id=NNN  صفحة المجلس (060–070 المائدة، 071–082 الأنعام)
index.json         فهرس عام (suras: maidah + anam)
data/NNN.json      بيانات كل مجلس (مقاطع منطوقة موقوتة + آيات/عناوين ثابتة)
audio/NNN.mp3      صوت مضغوط 48kbps mono
pdf/NNN.pdf        النسخة الأكاديمية المنقّحة لكل مجلس (زر التحميل)
texts/NNN.txt      نص الموقع المعتمد للبناء (المهذب الموافق للمنطوق)
assets/            css/js والأيقونة
tools/             أدوات المسار: جلب، تنزيل، مهذبة، بناء، فهرس، تحقق
VERIFICATION.md    تقرير مطابقة الآيات والمحاذاة
```

> `raw/` (استجابة Scribe الخام) و`_media/` (الصوت الأصلي والمفتاح والأدوات المؤقتة) محليان ولا يُرفعان.

## شكل `data/NNN.json`

```json
{
  "id": "062",
  "title": "تفسير سورة المائدة من الآية 27 إلى الآية 39",
  "speaker": "د. عبد الرحمن بن معاضة الشهري",
  "series": "تفسير سورة المائدة",
  "channel": "دورة الأترجة القرآنية",
  "language": "ar",
  "duration": 1884.0,
  "youtube_id": "…",
  "source_editions": ["scribe_v2 (timestamps)", "scribe_polished + reviewed (text)"],
  "segments": [
    { "type": "heading", "timed": false, "text": "المقدمة والمدخل إلى موضوع المجلس" },
    { "type": "text", "timed": true, "start": 63.2, "end": 70.1,
      "text": "بسم الله الرحمن الرحيم، الحمد لله …",
      "words": [ { "text": "بسم", "start": 63.2, "end": 63.5 }, … ] },
    { "type": "quran", "timed": false, "ref": "المائدة ٣١", "text": "﴿ … ﴾" }
  ]
}
```

- `type`: `text` منطوق موقوت · `quran` آية ثابتة · `heading` عنوان ثابت.
- كلمات التلاوة المنطوقة تبقى موقوتة داخل المقاطع، وكتلة الآية تُعرض للقراءة.
- المراجع بأرقام مشرقية، والآيات مقابلة مع طبعة `quran-uthmani`.

## أدوات المسار (tools/)

| الأداة | الوظيفة |
|---|---|
| `fetch_playlist.py` | جلب بيانات قائمة التشغيل → `config.json` |
| `download_audio.py` | تنزيل الصوت إلى `_media/src/NNN.m4a` |
| `make_txt.py` | مسودة النص المهذب من التفريغ (كشف التلاوات + المعجم) |
| `build_data.py` | بناء `data/NNN.json` من النص مع محاذاة difflib العالمية |
| `gen_index.py` | توليد `index.json` للسورتين |
| `verify_verses.py` | مقابلة كتل الآيات مع `quran-uthmani` |

**إعادة بناء المائدة بعد أي تعديل على نصوصها** (المصدر: `خلود/نصوص/المائدة/ملفات_TXT`):

```bash
for id in 060 061 062 063 064 065 066 067 068 069 070; do
  PYTHONIOENCODING=utf-8 python tools/build_data.py $id < texts/$id.txt > data/$id.json
done
PYTHONIOENCODING=utf-8 python tools/gen_index.py > index.json
PYTHONIOENCODING=utf-8 python tools/verify_verses.py
```

مؤشر قبول المحاذاة ≥ 95% (الواقع الحالي 97–100%). تفاصيل المسار والدروس التقنية
في مهارة `.agents/skills/tafseer-surah-expansion/`.

## المصدر والحقوق

المقاطع منشورة على قناة **دورة الأترجة القرآنية** على يوتيوب (الروابط في `index.json`
وكل ملف)، وأسماؤها ومددها مطابقة للتسجيلات الأصلية. النص والتقديم خدمة للطلاب،
والنسخة الأكاديمية PDF مراجعة بشرية. الآيات معروضة للاستئناس ويُرجى مقابلة
المصحف المطبوع في المسائل الدقيقة.
